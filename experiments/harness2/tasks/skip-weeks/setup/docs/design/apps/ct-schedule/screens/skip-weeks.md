# CT のお休み週

- アプリ: [CT スケジュール](../../ct-schedule.md)

## 目的

祝日以外で CT を休みにする週（年末年始、全社イベントなど）を登録・削除する。登録した週は、CT組み合わせ表で祝日の週と同じように「CT なし」になる。

## 使う人と場面

- ログインしたチームメンバーなら誰でも使う。実際に触るのは、年に数回、予定を知った人
- 「来月の全社合宿の週を休みにしておこう」と思い立ったときに開き、1件登録して閉じる
- 端末は PC

## 開き方と移動先

- URL: `/skip-weeks`
- どこから開くか: CT組み合わせ表の「お休み週を設定する」
- どこへ移れるか: CT組み合わせ表（パンくず「CT組み合わせ表」）

## 表示と操作

### 登録済みのお休み週

| 表示 | 内容 |
| --- | --- |
| 週 | 月曜の日付（例: 2026/12/28(月)）。近い順 |
| 理由 | 登録した人が書いた理由（例: 年末年始）。最大40文字 |
| 登録した人 | アバターと名前 |
| 過ぎた週 | 今日より前の週は出さない |

| 操作 | 挙動 |
| --- | --- |
| お休み週を追加する | 入力ダイアログを開く |
| 削除する | 確認を挟んで削除する。削除するとその週の CT は通常どおり組まれる |

### 追加のダイアログ

| 表示 | 内容 |
| --- | --- |
| 週 | 今週から1年先までの月曜から選ぶ。祝日の週と登録済みの週は選べない |
| 理由 | 必須。最大40文字 |

| 操作 | 挙動 |
| --- | --- |
| 追加する | 保存してダイアログを閉じ、一覧に足す。「お休み週を追加しました」と知らせる |
| キャンセル | 何もせずに閉じる |
| 理由が空 | 保存せず「理由を入力してください」 |

## 状態で変わること

- ログインしていないとき: 一覧は見られる。追加・削除の操作は出さず、ログインすると設定できることを伝える
- 登録が0件のとき: 「登録されているお休み週はありません」と、追加の操作
- 理由が長い（40文字）とき
- 保存・削除に失敗したとき: 「お休み週の追加に失敗しました」「お休み週の削除に失敗しました」

## こうなると困ること

- 間違えて別の週を削除し、その週の CT が組まれてしまう
- 祝日の週を重ねて登録してしまう

## 決まっている文言

- ページタイトル「CT のお休み週」
- 「お休み週を追加」「週」「理由」「追加」「キャンセル」「削除」
- 削除の確認: 「お休み週を削除」「2026/12/28(月) のお休みを削除しますか？この週の CT は通常どおり組まれます。」
- 「お休み週を追加しました」「お休み週を削除しました」「理由を入力してください」「登録されているお休み週はありません」
