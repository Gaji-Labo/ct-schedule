# マイページ

- アプリ: [CT スケジュール](../../ct-schedule.md)

## 目的

ログインしている人が、自分の今後の CT の相手を週ごとに確かめ、自分の設定（CT への参加、社員番号、Slack の個人チャンネル）を変える。

## 使う人と場面

- ログインしたチームメンバー本人だけが開く
- 「来週以降、誰と当たるか」を前もって知りたいとき、休職・復帰で参加を切り替えるとき、uチャンネルを作り直したときに開く。滞在は短い
- 端末は PC が主。スマホで開くこともある

## 開き方と移動先

- URL: `/me`
- どこから開くか: ヘッダーのユーザーメニュー「マイページ」
- どこへ移れるか: CT組み合わせ表（パンくず「CT組み合わせ表」）、相手との Slack ハドル

## 表示と操作

### 自分の今後の CT

| 表示 | 内容 |
| --- | --- |
| 週 | 今週から8週先まで、近い週から順に1行ずつ。日付（例: 2026/11/02(月)） |
| 今週 | 今週の行が、ほかの週と区別できる |
| 相手 | その週の相手のアバターと名前 |
| お休み | 自分がお休みの週は、相手の代わりに「お休み」 |
| 祝日 | 祝日の週は、相手の代わりに「CT なし」と祝日名 |
| 不参加のとき | 自分が CT に参加していないときは、一覧の代わりに「CT に参加していません」と、参加に切り替えられることを伝える |

| 操作 | 挙動 |
| --- | --- |
| ハドルを開始する | 相手の uチャンネルで Slack ハドルを開く。相手に uチャンネルが設定されていて、今週の行のときだけ出す |

### 自分の設定

| 表示 | 内容 |
| --- | --- |
| 名前・アイコン | Slack から取り込んだもの。ここでは変えられない |
| CT に参加する | 参加・不参加の切り替え |
| 社員番号 | 必須。数字だけ |
| Slack の個人チャンネル（uチャンネル） | チャンネル ID（例: C0123ABCD）。空でもよい |

| 操作 | 挙動 |
| --- | --- |
| 保存する | 入力を確かめて保存する。保存中はボタンを押せなくする。結果を「設定を保存しました」「設定の保存に失敗しました」で知らせる |
| 社員番号が空・数字以外 | 保存せず、入力欄のそばに「社員番号を数字で入力してください」 |

## 状態で変わること

- ログインしていないとき: このページは開けない（ここでは用意しない）
- 参加していないとき: 「今後の CT」は一覧の代わりに案内を出す
- uチャンネルが未設定のとき: 設定欄の uチャンネルが空。相手から自分へのハドルが始められないことを伝える
- 保存中・保存に失敗したとき

## こうなると困ること

- 今週の相手がすぐに見つからない
- 参加をやめるつもりが、ほかの設定を消してしまう
- 保存できたのかどうかわからない

## 決まっている文言

- ページタイトル「マイページ」、セクション見出し「今後の CT」「設定」
- 「お休み」「CT なし」「ハドルを開始」「CT に参加していません」
- 「CTに参加する」「社員番号」「Slack の個人チャンネル」「保存」
- 「設定を保存しました」「設定の保存に失敗しました」「社員番号を数字で入力してください」

## 未決のこと

- 未決: 参加をやめたときに、確認を挟むかどうか
