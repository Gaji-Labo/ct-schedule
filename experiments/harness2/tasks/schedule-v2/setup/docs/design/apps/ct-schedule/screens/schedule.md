# CT組み合わせ表

- アプリ: [CT スケジュール](../../ct-schedule.md)

既存の実装（`src/app/page.tsx`）と、アプリの md から書き起こした。

## 目的

今週の CT の相手を確かめ、相手との Slack ハドルを始める。開いてすぐ「今週、自分は誰と話すか」がわかり、その相手との通話を始められること。

## 使う人と場面

- チームメンバー全員。全員が閲覧者で、ログインした人は自分の設定も変えられる
- 月曜の CT 前に「今週の相手は誰か」を確かめ、そのまま相手との通話を始める。滞在は数十秒で終わる
- Slack の自動投稿から来た人も、ブックマークから来た人もここに着く
- 端末は PC が主。Slack の投稿からスマホで開くこともある
- たまに起きること: 初めて使う人の設定、休職などで参加をやめる・戻る、退職者を外す
- 画面の外で起きること: 毎週月曜 11:00 に、その週のペアが Slack チャンネルへ自動投稿される（CT 自体は 14:00 開始）。アプリはこの投稿からのリンク先にもなる

## 開き方と移動先

- URL: `/`
- どこから開くか: アプリの入口。Slack の自動投稿のリンク、ブックマーク。メンバー一覧のパンくず「CT組み合わせ表」からも戻ってくる
- どこへ移れるか: メンバー一覧（「メンバー一覧を見る」）、相手との Slack ハドル

## 表示と操作

### 参加者の人数

| 表示 | 内容 |
| --- | --- |
| 参加者の人数 | 「CTの参加者：○人」。参加者（`participate` が true）の数。メンバー一覧の「参加（○人）」と一致する |
| メンバー一覧へのリンク | 「メンバー一覧を見る」。人数の数字そのものはリンクにしない |

| 操作 | 挙動 |
| --- | --- |
| 「メンバー一覧を見る」を押す | メンバー一覧（`/member`）へ移る |

### 週ごとの組み合わせ

| 表示 | 内容 |
| --- | --- |
| 週 | 今週から12週先まで、月曜日ごとに1つ。日付（曜日つき。例: 2026/10/19(月)）。過去の週は出さない |
| 今週 | 今日を含む週の月曜（今日が月曜なら今日）。今週とそれ以降の週が区別できる |
| 組み合わせ | 2人1組のペア。番号、2人のアバターと名前 |
| 人の表示 | Slack のアイコンと名前。アイコンが無い人は名前の頭文字で代用し、背景色は人ごとに固定の色にする（どの画面でも同じ人は同じ色） |
| お休み | 参加者が奇数の週は、1人が「お休み」になる |
| 祝日 | 祝日の週は組み合わせを出さず、「CT なし」であることと祝日名を出す。通常の週とはひと目で区別できる |
| CT の開始時刻 | 月曜 14:00 |
| 先の週 | 「予定」であること（参加者の増減で組み変わるため） |

| 操作 | 挙動 |
| --- | --- |
| 次の週・前の週へ送る | 表示する週を進める・戻す。最初は「次の週」だけ送れる |
| ハドルを開始する | ペアごとに、相手の uチャンネルで Slack ハドルを開く（1クリックで Slack が開く）。相手に uチャンネルが設定されているときだけ出す |
| 特定の人と次に当たるのはいつかを調べる | 人を選ぶと、その人と次に組む週がわかる |

## 状態で変わること

- ログインしていないとき: 右上に Slack でログインするボタンを出す。ここまでの表示と操作はすべて見られる。ログインすると何ができるか（参加の切り替え、自分のペアの強調）を伝える
- ログインしているとき: 右上にユーザーメニュー（プロフィール編集、ログアウト）を出す。今週の自分の相手（またはお休みであること）を、他のペアより先に・目立つ形で示す。先の週でも自分の行がわかる
- ログインしていて、社員番号か Slack の個人チャンネルが未設定のとき: 初回の設定ダイアログ（名前、社員番号、uチャンネル、CTに参加する）を開く
- 参加者が奇数の週: 1人が「お休み」になる
- 祝日の週: 組み合わせの代わりに「CT なし」と祝日名を出す
- 参加者が2人未満で組み合わせを作れないとき: 「参加者が2人以上になると組み合わせが表示されます」と出す

## こうなると困ること

- 今週の相手がすぐに見つからない
- 参加者の人数とメンバー一覧の人数が食い違って見える

## 決まっている文言

- 「CTの参加者：○人」「メンバー一覧を見る」「お休み」「ハドルを開始」「CT なし」
- 組み合わせを作れないとき: 「参加者が2人以上になると組み合わせが表示されます」
- 初回の設定ダイアログ: 「設定」「CT表の表示に必要な情報を設定してください」「CTに参加する」「保存」「設定が完了しました」「設定に失敗しました」

## 決まっていること（見せ方）

- 週ごとの組み合わせはカードにして、今週を左端に「次の週」「前の週」で週ごとに横に送って見せる
