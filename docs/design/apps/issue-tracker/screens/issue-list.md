# Issue一覧

- アプリ: [Issueトラッカー](../../issue-tracker.md)

依頼文から書き起こした。

## 目的

リポジトリの Issue の中から目的のものを見つけ、状態を確かめて開く。新しい Issue を書く入口でもある。

## 使う人と場面

- 保守するチームのメンバーが、1日に何度も開く。自分の担当の確認、新しく来た Issue の振り分け、似た Issue が無いかの確認
- 外から来た人が、起票の前に同じ報告が無いかを探す
- 件数が多い（オープン 1,048件、クローズ 5,614件）。1ページに25件ずつ出す

## 開き方と移動先

- URL: `/issues`
- どこから開くか: 未決
- どこへ移れるか: Issue詳細（今回は対象外）、Issue の作成画面（今回は作らない）

## 表示と操作

### Issue（1件ごと）

| 表示 | 内容 |
| --- | --- |
| 状態 | オープン、クローズ（完了）、クローズ（対応しない）のどれか |
| 題名 | 自由な文。長いものもある（80字を超えることがある）。コマンド名などのコードを含むことがある |
| ラベル | 0個から複数。ラベルごとに決まった色がある |
| 番号 | 例: #14931 |
| 作成者 | ユーザー名 |
| 作成日時 |  |
| 閉じた人と日時 | クローズの Issue だけ。例: 「〜が 2026/11/03 に閉じた」 |
| コメント数 | 0件のこともある |
| 紐づくプルリクエストの数 | あるときだけ |
| 担当者 | いるときだけ。複数のこともある |

| 操作 | 挙動 |
| --- | --- |
| Issue を開く | その Issue の詳細へ移る |
| 作成者・ラベルを選ぶ | その作成者・ラベルで一覧を絞り込む |

### 一覧全体

| 表示 | 内容 |
| --- | --- |
| 件数 | 今の条件でのオープンの件数とクローズの件数 |
| 検索の条件 | 今の条件を文字で（例: `is:issue state:open`）。直接書き換えて検索できる |

| 操作 | 挙動 |
| --- | --- |
| オープン / クローズを切り替える | 一覧をその状態の Issue に切り替える |
| 検索する | 自由な語と条件（`label:bug` など）で探す |
| 絞り込む | 作成者・ラベル・プロジェクト・マイルストーン・担当者・種類で絞る。それぞれ候補から選ぶ |
| 並べ替える | 新しい順（既定）・古い順・コメントが多い順・更新が新しい順 |
| 新しい Issue を作る | 作成画面へ移る（作成画面はここでは作らない） |

## 状態で変わること

- 1ページに25件ずつ出す
- 未決: ログインの有無・権限で変わること（[アプリの md](../../issue-tracker.md) の「未決のこと」）

## こうなると困ること

- 目的の Issue が、ほかの情報に埋もれて見つからない
- 今オープンとクローズのどちらを見ているのかわからない
- 新しい Issue を書きたい人が、入口を見つけられない
- 0件のとき、壊れているのか結果が無いのかわからない

## 未決のこと

- 未決: どこから開くか（アプリのトップか、別の画面からか）
- 未決: 0件のときの文言
- 未決: 読み込みに失敗したときの文言・できること
- 未決: ページ送りの見せ方（ページ番号か、前後だけか）
