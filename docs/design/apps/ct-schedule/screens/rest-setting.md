# お休みの設定

- アプリ: [CT スケジュール](../../ct-schedule.md)

[Issue #37「お休みの手動設定」](https://github.com/Gaji-Labo/ct-schedule/issues/37) と、聞き取りから書き起こした。

## 目的

不在などで CT に参加できない場合、手動でお休みを設定できるようにする。

## 使う人と場面

- 本人が、自分のお休みだけを設定する
- 予定が決まったときに PC から前もって登録することも、当日の朝にスマホから登録することもある

## 開き方と移動先

- URL: 未決
- どこから開くか: CT組み合わせ表の週カード
- どこへ移れるか: 未決

## 表示と操作

### お休みの登録

| 表示 | 内容 |
| --- | --- |
| 週 | お休みにする週。週（月曜日）を1つずつ選ぶ |

| 操作 | 挙動 |
| --- | --- |
| 週をお休みにする | その週の自分の CT をお休みにする。ペアは自動で組み直されるとよい（Issue #37） |

### 登録したお休み

| 表示 | 内容 |
| --- | --- |
| 登録したお休みの一覧 | 自分が登録したお休みの週 |

| 操作 | 挙動 |
| --- | --- |
| お休みを取り消す | 一覧からお休みを取り消す |
