# CT組み合わせ表

- アプリ: [CT スケジュール](../../ct-schedule.md)

既存の実装（`src/app/page.tsx`）と、アプリの md から書き起こした。

## 目的

今週の CT の相手を確かめ、相手との Slack ハドルを始める。

## 使う人と場面

- チームメンバーが、週の初めに「今週の相手は誰か」を確かめるために開く
- 滞在時間は短い。「相手を知る → ハドルを始める」で終わる

## 開き方と移動先

- URL: `/`
- どこから開くか: アプリの入口。メンバー一覧のパンくず「CT組み合わせ表」からも戻ってくる
- どこへ移れるか: メンバー一覧（「メンバー一覧を見る」）、相手との Slack ハドル

## 表示と操作

### 参加者の人数

| 表示 | 内容 |
| --- | --- |
| 参加者の人数 | 「CTの参加者：○人」。参加者（`participate` が true）の数。メンバー一覧の「参加（○人）」と一致する |
| メンバー一覧へのリンク | 「メンバー一覧を見る」。人数の数字そのものはリンクにしない |

| 操作 | 挙動 |
| --- | --- |
| 「メンバー一覧を見る」を押す | メンバー一覧（`/member`）へ移る |

### 週ごとの組み合わせ

| 表示 | 内容 |
| --- | --- |
| 週 | 今日以降の月曜日ごとに1つ（今日が月曜なら今日から）。日付（例: 2026/10/19(月)） |
| 組み合わせ | 2人1組のペア。番号、2人のアバターと名前 |
| お休み | 参加者が奇数の週は、1人が「お休み」になる |
| 祝日 | 祝日の週は組み合わせを出さず、祝日名を出す |
| 今週 | 最初の週（今週）を強調する |

| 操作 | 挙動 |
| --- | --- |
| 次の週・前の週へ送る | 表示する週を進める・戻す。最初は「次の週」だけ送れる |
| ハドルを開始する | 相手との Slack ハドルを開く。相手に Slack の個人チャンネルが設定されているときだけ出す |

## 状態で変わること

- ログインしていないとき: 右上に Slack でログインするボタンを出す
- ログインしているとき: 右上にユーザーメニュー（プロフィール編集、ログアウト）を出す
- ログインしていて、社員番号か Slack の個人チャンネルが未設定のとき: 初回の設定ダイアログ（名前、社員番号、uチャンネル、CTに参加する）を開く
- 参加者が奇数の週: 1人が「お休み」になる
- 祝日の週: 組み合わせの代わりに祝日名を出す

## こうなると困ること

- 今週の相手がすぐに見つからない
- 参加者の人数とメンバー一覧の人数が食い違って見える

## 決まっている文言

- 「CTの参加者：○人」「メンバー一覧を見る」「お休み」「ハドルを開始」
- 初回の設定ダイアログ: 「設定」「CT表の表示に必要な情報を設定してください」「CTに参加する」「保存」「設定が完了しました」「設定に失敗しました」

## 決まっていること（見せ方）

- 週ごとの組み合わせはカードにして、横に送って見せる（`CTScheduleCarousel`）

## 未決のこと

- 未決: 参加者が2人未満で組み合わせを作れないときに出す文言
- 未決: 何週先まで表示するか（今はコードの設定で決まっている）
