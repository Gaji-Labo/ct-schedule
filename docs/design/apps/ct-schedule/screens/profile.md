# プロフィール編集

- アプリ: [CT スケジュール](../../ct-schedule.md)

## 目的

CT の相手を知るため。自分のプロフィール（写真、表示名、uチャンネル、一言コメント、属性・役職）を設定する。

## 使う人と場面

- 本人と管理者が編集できる
- プロフィールは基本最初に設定し、そこまで頻繁に変えない想定
- 基本 PC から

## 開き方と移動先

- URL: `/profile`（管理者が他人のプロフィールを直すときは `/member/[id]/edit`。仮置き）
- どこから開くか: ヘッダーのユーザーメニュー（今はここからプロフィール編集のダイアログを開いている）
- どこへ移れるか: 未決（保存したあと）

## 表示と操作

### プロフィール

| 表示 | 内容 |
| --- | --- |
| 写真 | デフォルトは Slack アイコン。差し替えが可能 |
| 表示名 | 今の「名前」（`slack_display_name`） |
| uチャンネル | Slack のチャンネルから選ぶ（`slack_u_channel_id`） |
| 一言コメント | 新しい項目 |
| 属性・役職 | 自由入力で任意。新しい項目 |

| 操作 | 挙動 |
| --- | --- |
| 写真を差し替える | 写真を選ぶ → Slack アイコンの代わりに表示される |
| 写真を元に戻す | 差し替えた写真をやめ、Slack アイコンに戻す |
| 保存する | 入力した内容を保存する |

## 状態で変わること

- ログインしていないとき: トップに戻す
- 本人が開いたとき（`/profile`）: 自分のプロフィールを編集する
- 管理者が他人のプロフィールを開いたとき（`/member/[id]/edit`。仮置き）: そのメンバーのプロフィールを編集する
- 写真を差し替えていないとき: Slack アイコンを表示する

## こうなると困ること

- 写真を差し替えたあと、元の Slack アイコンに戻せない

## 未決のこと

- 未決: 保存したあとの移動先
- 未決: 社員番号・「CTに参加する」をこの画面に残すか（決める人: 実装に任せる）
- 未決: 管理者が他人を編集する URL（`/member/[id]/edit` は仮置き）
