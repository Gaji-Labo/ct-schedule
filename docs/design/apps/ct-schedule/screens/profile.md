# プロフィール編集

- アプリ: [CT スケジュール](../../ct-schedule.md)

聞き取りと、既存の「プロフィール編集」ダイアログ（`src/app/components/UserDropdown.tsx`）から書き起こした。

## 目的

本人が自分のプロフィールを直す。今はダイアログで直しているものを、専用ページにして URL で開けるようにする。

## 使う人と場面

- 本人が自分の分を直す（他のメンバーの分は直さない）

## 開き方と移動先

- URL: `/profile`
- どこから開くか: ヘッダーのアバターのメニューの「編集」
- どこへ移れるか: 未決（下の「未決のこと」）

## 表示と操作

### プロフィール

| 表示 | 内容 |
| --- | --- |
| 名前 | 必須。今の値（`slack_display_name`）が入った状態で開く |
| 社員番号 | 数字。必須。今の値が入った状態で開く |
| uチャンネル | Slack のチャンネルから選ぶ。必須。今の値が選ばれた状態で開く |
| CTに参加する | オン・オフ。今の値の状態で開く |

| 操作 | 挙動 |
| --- | --- |
| 保存する | 4項目を保存する → 「更新しました」。失敗したら「更新に失敗しました」 |
| キャンセルする | 保存せずに戻る（戻り先は未決） |

## 状態で変わること

- 本人の分しか更新できない（サーバー側で確かめている。他人の分は「他人のプロフィールは更新できません」）
- ログインしていないとき: 未決

## こうなると困ること

未決（下の「未決のこと」）

## 決まっている文言

既存のダイアログで使っているもの。

- 項目名: 「名前」「社員番号」「uチャンネル」「CTに参加する」
- 「uチャンネルを選択」（uチャンネルの選択前の表示）
- ボタン: 「キャンセル」「保存」
- 保存のあと: 「更新しました」「更新に失敗しました」

## 未決のこと

- 未決: 保存したあと、そのページのままか、トップ（CT組み合わせ表）に戻るか
- 未決: キャンセルしたときの戻り先
- 未決: ログインしていないときに開いたらどうするか（ログインを促す、トップに移すなど）
- 未決: 直したくなる場面と、こうなると困ること（例: 参加をやめたのに組み合わせに入ってしまう、保存できたか分からない）
