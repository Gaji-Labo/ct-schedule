# メンバー一覧

- アプリ: [CT スケジュール](../../ct-schedule.md)

既存の実装（`src/app/member/page.tsx`）と、アプリの md から書き起こした。

## 目的

メンバー（Slack 連携で登録された社員全員）が CT に参加しているかを確かめる。不要になったメンバーを削除する。

## 使う人と場面

- チームメンバーが、誰が CT に参加しているかを確かめるときに開く
- メンバーの削除は、たまにしか行わない

## 開き方と移動先

- URL: `/member`
- どこから開くか: CT組み合わせ表の「メンバー一覧を見る」
- どこへ移れるか: CT組み合わせ表（パンくず「CT組み合わせ表」）

## 表示と操作

### 参加

| 表示 | 内容 |
| --- | --- |
| 見出し | 「参加（○人）」。人数は CT組み合わせ表の「CTの参加者：○人」と一致する |
| メンバー | 参加者ごとに、アバター、名前、参加状態（「参加」）。社員番号の順 |

| 操作 | 挙動 |
| --- | --- |
| 削除する | 確認ダイアログを開く → 「削除」でメンバーを削除し、一覧から消す |

### 不参加

| 表示 | 内容 |
| --- | --- |
| 見出し | 「不参加（○人）」 |
| メンバー | 不参加のメンバーごとに、アバター、名前、参加状態（「不参加」）。社員番号の順 |

| 操作 | 挙動 |
| --- | --- |
| 削除する | 「参加」と同じ |

## 状態で変わること

- ログインしていないとき: 右上に Slack でログインするボタンを出す。削除はできない
- ログインしているとき: 右上にユーザーメニューを出す。各メンバーの右端に削除ボタンを出す
- 参加者が0人のとき: 「CTに参加しているメンバーはいません」
- 不参加のメンバーが0人のとき: 「不参加のメンバーはいません」

## こうなると困ること

- 間違えて別のメンバーを削除してしまう
- 「参加」の人数と、CT組み合わせ表の参加者の人数が食い違って見える

## 決まっている文言

- 「参加（○人）」「不参加（○人）」
- 「CTに参加しているメンバーはいません」「不参加のメンバーはいません」
- 削除の確認: 「メンバーを削除」「○○ を削除しますか？」「キャンセル」「削除」
- 削除のあと: 「○○ を削除しました」「メンバーの削除に失敗しました」

## 未決のこと

- 未決: 削除できる人を、ログインしている人全員にするか、管理する人に限るか
