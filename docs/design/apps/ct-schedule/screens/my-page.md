# マイページ

- アプリ: [CT スケジュール](../../ct-schedule.md)

## 目的

全員分ではなく自分のみに絞ってペアを見たい。プロフィールを編集する。

## 使う人と場面

- 自分が週の初めにPCで開く

## 開き方と移動先

- URL: 未決
- どこから開くか: Header内のアイコンから表示されるポップアップの「マイページ」
- どこへ移れるか: 未決

## 表示と操作

### ペア

| 表示 | 内容 |
| --- | --- |
| 自分のペア | 先1ヶ月分くらい |

### プロフィール編集

今の「編集」ダイアログ（`src/app/components/UserDropdown.tsx`）と同じ項目を編集できる。

| 表示 | 内容 |
| --- | --- |
| 名前 | 自分の名前 |
| 社員番号 | 自分の社員番号 |
| uチャンネル | Slack のチャンネルから選ぶ |
| CTに参加する | 参加するかどうか |

| 操作 | 挙動 |
| --- | --- |
| 保存する | プロフィールを更新する |
