# Elevation & Depth

**階層は枠線で表し、影は「画面から浮いて、ほかの要素に重なるもの」にだけ付けます。**

- 基調は「静かな UI」（docs/design/principles.md「デザイン原則」）。面の区切りを影で立体的に見せない
- ダークモードでは影がほとんど見えないため、どの階層でも **枠線を必ず付ける**。影は補助
- 影の強さは2段階だけ（`shadow-md` / `shadow-lg`）。`shadow-sm`・`shadow`・`shadow-xl` 以上は使わない

## 判断のしかた

| こんなとき | 使うもの |
| --- | --- |
| カードやリストを背景から区切りたい | `border`（必要なら `bg-muted` などの面の色）。影は付けない |
| 選択中のカードなど、1つだけ目立たせたい | 枠線の色や太さ（`border-2` など）。影で浮かせない |
| ボタン・入力欄・バッジ | 部品の既定のまま（影なし）。`className` で影を足さない |
| メニュー・選択肢・toast のように、ほかの要素の上に一時的に出る | `border shadow-md`（部品に組み込み済み） |
| カルーセルの前後ボタンをカードに重ねて置くときのように、ほかの要素の上に重ねて置く | `shadow-md` |
| ダイアログ | `border shadow-lg` ＋ オーバーレイ（`Dialog` に組み込み済み） |
