# Colors

## Semantic

コンポーネントから使う色です。Tailwind のクラス (`bg-primary`、`text-muted-foreground` など) で指定します。
ツールバーでダークテーマに切り替えると、ダーク時の値を確認できます。

<SemanticColorTable />

## Primitive

Semantic トークンの参照先になる生の色値です。**コンポーネントからは直接使いません。**

<PrimitivePalette />

## Brand (Gaji-Labo)

Gaji-Labo のブランドカラーです。出典は Figma「Gaji-Labo Styles」の Gaji-Labo Colors（Main は Web Site、Accent は Blog の定義）。
用途は Web サイト・ブログでの使われ方をそのまま載せています。

**Primitive なので、コンポーネントからは直接使いません。** アプリで使うときは、用途に合う Semantic トークンを追加し、その参照先にします（DESIGN.md「色」）。
